# Cricket Statistics Tracker
[Demo Video](https://youtu.be/Q5xnEUc2oH8)

A battery-powered, rechargeable desk widget for tracking cricket scores. It uses a microcontroller to get current game scores via a JavaScript wrapper calling a cricket score API. The **SSD1306 128x64 OLED screen** displays the scores, and a **rotary encoder** lets you cycle through match options. Scores automatically refresh every 20 seconds, keeping your display up to date.
